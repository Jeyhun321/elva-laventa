## Что делать дальше — владельцу

Остались ровно два ручных production-действия — из текущего окружения нет Supabase CLI, management token/project link или DB password:

1. **Применить SQL.** Supabase → SQL Editor → New query → вставить `supabase/fix-order-any-auth.sql` целиком → Run. Файл повторно проверен: функциональная разница с Telegram-версией — только удаление Google-provider блока; `auth.uid()`, server-side цена, размеры, Telegram, очистка корзины и grants не изменены.
2. **Выключить подтверждение email.** Read-only production-проверка 2026-08-01 показала `mailer_autoconfirm: false` (Confirm email включён), Google provider включён. В панели:
   - Authentication → Sign In / Providers → **Email** → выключить **Confirm email** → Save.
   - Уже зарегистрированным с неподтверждённой почтой: Authentication → Users → «…» у пользователя → **Confirm email**.
3. **Живая проверка на реальных аккаунтах:**
   - Email-покупатель: регистрация → вход → корзина → оформление заказа (заказ должен дойти и в базу, и в Telegram).
   - Google-аккаунт: корзина и избранное на месте.
   - A login → данные A → logout → пусто → B login → только B → logout → пусто → A login → снова A.
