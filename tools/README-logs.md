# Просмотр системных логов локально

Инструмент показывает системные логи сайта (`system_logs` в Supabase) прямо
в терминале, в реальном времени. Он ходит **напрямую в базу**, минуя сайт и
админ-панель, — поэтому работает, даже если сайт или админка недоступны.

## Разовая настройка (1 раз)

1. Открой Supabase → **Project Settings → API**.
2. Скопируй **Project URL** и ключ **`service_role`** (секретный, не `anon`).
3. В папке `tools/` скопируй `.env.logs.example` в `.env.logs` и впиши свои значения:

   ```
   SUPABASE_URL=https://твой-проект.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=твой_service_role_ключ
   ```

Файл `tools/.env.logs` уже в `.gitignore` — в репозиторий он не попадёт.

> ⚠️ `service_role` ключ обходит всю защиту базы. Держи `.env.logs` только у себя,
> не показывай, не коммить, не вставляй в браузер публичного сайта.

## Запуск

```bash
npm run logs
```

Появится живая лента: новые события подтягиваются каждые 5 секунд. `Ctrl+C` — выход.

### Опции

```bash
npm run logs -- --once            # показать последние и выйти (без опроса)
npm run logs -- --level error     # только ошибки (error | warning | info)
npm run logs -- --interval 10     # интервал опроса, сек (минимум 2)
npm run logs -- --limit 100       # сколько последних строк показать на старте (1–500)
npm run logs -- --help            # справка
```
