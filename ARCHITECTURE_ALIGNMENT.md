# Сверка Elva LaVenta с `marketplace-az-architecture.md`

## Важное решение по масштабу

Документ описывает большой мультипродавецкий маркетплейс уровня Trendyol. Elva LaVenta сейчас — магазин одного бренда. Поэтому правильный следующий шаг — **модульный монолит**: одна понятная система с независимыми модулями, которую можно расширять без дорогой и рискованной переделки.

Не добавляем сейчас кабинеты продавцов, выплаты продавцам и сложные микросервисы: для одного магазина это увеличит цену, сложность и риск ошибок, но не даст пользы покупателю.

## Что уже соответствует документу

- Каталог, категории, карточки товаров, несколько фотографий и коды товаров.
- Азербайджанский язык по умолчанию, русский и английский переводы.
- Авторизация Google, профили клиентов, отдельная админ-панель.
- Заказы и позиции заказа хранятся в PostgreSQL (Supabase).
- Уведомления о новых заказах в Telegram.
- Отдельное хранилище изображений в Supabase Storage.
- Проверки обязательных полей заказа и размера товара в интерфейсе.

## Добавлено по архитектуре сейчас

- Серверная корзина: товары корзины хранятся у конкретного аккаунта, а не только в браузере.
- Серверное избранное: у каждого пользователя свой список избранного.
- Мягкая миграция: старые локальные корзины переносятся в базу при первом входе.
- Политики доступа RLS: клиент видит и меняет только собственную корзину и избранное.
- Только администратор может изменять товары и категории в базе.
- Заказ создаётся только защищённой серверной функцией и только для вошедшего через Google пользователя.
- На уровне базы проверяются: вход, Google-аккаунт, обязательные поля, пустая корзина, существование/активность товара, количество и размер.

## Что пока не нужно добавлять, но запланировано при росте

- Варианты товара с отдельными остатками: `product_variants` и `inventory_stocks`.
- Полнотекстовый поиск PostgreSQL/OpenSearch и Redis-кеш.
- Онлайн-оплата: m10, Birbank/Kapital, Pasha Bank с 3DS. Не храним данные карт на сайте.
- Интеграции курьеров, пункты выдачи, расчёт доставки, VÖEN/VAT.
- SMTP с собственным доменом, SMS-провайдер и ограничения OTP.
- Журнал действий администратора, мониторинг, резервные копии, Cloudflare/WAF и HTTPS-проверки.
- Мультипродавецкая модель — только если Elva LaVenta действительно станет площадкой для других магазинов.

## Что нужно сделать в Supabase

Откройте **Supabase → SQL Editor → New query**, вставьте содержимое файла
[`marketplace-foundation.sql`](./supabase/marketplace-foundation.sql) и нажмите **Run**.

После этого корзины и избранное будут синхронизироваться между устройствами и будут жёстко разделены между аккаунтами.
