ELVA LAVENTA — МОБИЛЬНАЯ ВЕРСИЯ ГЛАВНОЙ СТРАНИЦЫ
Замеры сделаны в реальном рендере при 375x812. Дата: 2026-07-30.

================================================================
1. БРЕЙКПОИНТЫ (@media в src/styles/index.css)
================================================================
Размерные:
  1200px (min)  — товарная страница: боковая колонка товара показывается
  1000px        — каталог/корзина/товар в одну колонку
   900px        — ГЕРОЙ в одну колонку + центр, категории → горизонт. скролл,
                  футер 2 колонки, бейдж 86px, карусель 440px
   900px (2-й)  — оформление заказа и админка в одну колонку
   861px (min)  — галерея товара фиксированного размера
   860px        — товар/галерея перестраиваются
   780px        — ШАПКА переносится на 3 строки, поиск на всю ширину,
                  подписи под иконками скрыты, фильтры каталога горизонтально
   760px        — промо уже, мини-карточка героя по центру
   720px        — админ-строки и формы в одну колонку
   640px        — секции 60px, промо по центру, футер 1 колонка,
                  ссылка «Все товары» в шапке секции скрыта, аватары 32px
   640px (2-й)  — панель системных логов в одну колонку
   560px        — логотип мельче, строка корзины перестраивается

Возможностные (не по ширине):
  (hover: hover) and (pointer: fine) and (reduced-motion: no-preference)
       — ТОЛЬКО здесь прячется кнопка «в корзину» до наведения
  (max-width:760px), (pointer: coarse) — выкл. лепестки, 3D-наклон
  (hover: none) — «избранное» на карточке всегда видно
  (prefers-reduced-motion: reduce) — вся анимация выключена

2. СЕКЦИИ НА МОБИЛКЕ (<640px)
================================================================
HEADER   — 3 строки, высота 181px, sticky. Подписи под иконками скрыты.
           Логотип 150x50. Поиск отдельной строкой на всю ширину.
HERO     — 1 колонка, текст по центру, порядок прежний (текст → карусель).
           Заголовок 46px serif, описание 3 строки, статистика в 1 ряд.
MARQUEE  — без изменений, тонкая тёмная полоса 57px, бежит автоматически.
КАТЕГОРИИ— из сетки 7 колонок → горизонтальный скролл (780px в 311px),
           кружки 78→68px, есть scroll-snap, полоса прокрутки скрыта.
POPULAR  — сетка сворачивается в 1 КОЛОНКУ (8 карточек = 5325px высоты).
           Ссылка «Все товары» сверху скрыта, остаётся кнопка снизу.
PROMO    — колонки в столбик, текст по центру, отступы 40x26px.
FOOTER   — 4 колонки → 1 колонка. Подписка, ряд оплаты (перенос),
           копирайт и соцсети остаются в строку.

Размеры/отступы: секции 104px → 60px, боковые поля контейнера 32px,
заголовки секций clamp() уменьшаются автоматически.

3. ШАПКА НА МОБИЛКЕ
================================================================
Бургер ЕСТЬ, но он не «меню сайта», а кнопка КАТАЛОГА: иконка гамбургера
меняется на крестик (IconMenu/IconClose) + слово «Каталог». По тапу
открывается выпадающий список всех категорий. Отдельного бургер-меню
для навигации нет — и оно не нужно, горизонтального меню на сайте нет.

Что ВИДНО (ничего не спрятано в бургер):
  строка 1: логотип (150x50) + кнопка «Каталог» (119x44)
  строка 2: переключатель языка AZ/RU/EN, юзер-меню, избранное, корзина
  строка 3: поиск на всю ширину (261x45 + кнопка 48x45)
Что СКРЫТО: только текстовые подписи под иконками (.header-icon em).
Счётчики на корзине/избранном остаются видны.

4. ГЕРОЙ НА МОБИЛКЕ
================================================================
2 колонки → 1, всё выравнивается по центру. Порядок: бейдж → заголовок →
описание → 2 кнопки → соцпруф → статистика → карусель. Высота 1199px.
  Заголовок: 46.4px Cormorant, помещается в одну строку, italic-акцент цел.
  Кнопки: основная 196x51, текстовая 168x51 — обе крупные, ок.
  Соцпруф: 4 аватара по 32px внахлёст + текст, по центру.
  Статистика: 3 колонки в один ряд (44/101/47px) — помещается впритык.
  Бейдж «40%»: 86px, висит поверх правого верхнего угла карусели.
  Мини-карточка: центрируется внизу карусели (171x72).
  Parallax-tilt: ОТКЛЮЧЁН (и по ширине ≤760px, и по pointer: coarse,
  и внутри самого хука по matchMedia). Лепестки тоже отключены.

5. КАРТОЧКИ ТОВАРОВ
================================================================
На мобилке 1 КАРТОЧКА В РЯД (сетка minmax(250px,1fr), доступно 311px).
Hover-эффекты решены корректно:
  - Кнопка «в корзину» прячется ТОЛЬКО при (hover: hover)+(pointer: fine).
    На тач-устройстве блок не применяется вовсе — кнопка всегда видна (44x44).
  - «Избранное» — правило @media (hover: none) делает сердечко всегда видимым.
  - 3D-наклон и подъём карточки на тач отключены.
Тач-версия ничего не теряет.

================================================================
7. TOUCH / ЖЕСТЫ
================================================================
СВАЙПА В КАРУСЕЛИ ГЕРОЯ НЕТ. В Intro.jsx нет ни одного touch-обработчика
(onTouchStart/Move/End). Листать можно только:
  - автоматически (каждые 2.5 сек), либо
  - тапом по точкам внизу — а они 8x8px, попасть тяжело.
Пауза при наведении сделана на onMouseEnter/onMouseLeave — на тач-экране
эти события не срабатывают, поэтому остановить автопрокрутку пальцем нельзя.
Боковые карточки карусели кликабельны и ведут на товар — при попытке
«свайпнуть» палец может случайно открыть чужой товар.

КОНФЛИКТА СО СКРОЛЛОМ СТРАНИЦЫ НЕТ: горизонтально скроллится только
ряд категорий (scroll-snap, полоса скрыта), вертикальный скролл не перехвачен.
На интерактивных элементах стоит touch-action: manipulation — двойного
тап-зума и задержки 300мс нет.
