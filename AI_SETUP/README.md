# AI_SETUP

This folder stores everything needed to **back up and restore the full AI + development environment** used for the LaVenta project.

The goal: when moving to a new computer (or recovering after a reinstall), you can rebuild the exact same working setup — terminal, editor, AI CLIs, fonts and helper scripts — without guessing what was installed or how it was configured.

## What lives here

- **README.md** — this file (purpose overview).
- **INSTALL_GUIDE.md** — step-by-step installation instructions (placeholder for now).
- **BACKUP_CHECKLIST.md** — everything that must be backed up before switching computers.
- **NEW_PC_SETUP.md** — how to restore everything on a fresh machine (placeholder for now).
- **BACKUP_INFO.md** — explains what belongs in each subfolder.

## Subfolders

- **WindowsTerminal/** — Windows Terminal settings and profiles.
- **VSCode/** — VS Code settings, keybindings, extensions list.
- **ClaudeCode/** — Claude Code configuration and related files.
- **CodexCLI/** — Codex CLI configuration and related files.
- **Fonts/** — fonts used in the terminal and editor.
- **Scripts/** — helper/setup scripts (currently empty; to be added later).

## Important

- This folder is **documentation and backup material only**. It does not change the LaVenta application source code.
- Do not delete existing content when updating — only add or refine.
